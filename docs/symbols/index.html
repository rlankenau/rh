Greek letters and common symbols

How each letter and symbol is read, and what it stands for on this site. Several letters are used for more than one thing; the table says how to tell which.

Greek letters

LetterNameUsed here for
βbetaThe real part of a zero: a zero is written ρ = β + iγ. The Riemann Hypothesis says β = ½.
γgammaThree different things. (1) The imaginary part (height) of a zero, in chapters 2, 3 and A1. (2) Euler's constant ≈ 0.5772, written γEuler where both appear. (3) In chapters M1 and M2, the scale factor that defines the toy circle: t and γt are the same point.
Γcapital gammaThe gamma function, which extends the factorial to non-integers. It appears in the functional equation of zeta.
δdeltaA small quantity or a small change. In Masullo's paper, δz also means "evaluate a function at the point z".
εepsilonAn arbitrarily small positive number. "x½+ε" means "a power of x just barely above the square root".
ζzetaThe Riemann zeta function, ζ(s) = Σ 1/ns.
θthetaIn chapter A1, an exponent between 0 and 1 in a bound like xθ. Also the name of the "θ-functions" in the Masullo chapters.
Θcapital thetaA θ-function built from a function f: Θ(x) = √x · Σ f(nx).
Λcapital lambdaThe von Mangoldt function: Λ(n) = ln p if n is a power of the prime p, and 0 otherwise.
μmuA measure: the rule for assigning length or weight when integrating. On the positive reals the natural one for this subject is dt/t.
πpiTwo different things. With an argument, π(x) is the number of primes up to x. On its own it is the usual 3.14159…
Πcapital piProduct: multiply together all the terms described underneath it.
ρrhoA zero of the zeta function (or of an L-function) in the critical strip.
σsigmaThe real part of the complex variable s = σ + it.
Σcapital sigmaSum: add up all the terms described underneath it.
φ, ϕphiA test function (a smooth bump you choose). The two shapes of the letter are used for two different test functions, following the paper.
Φcapital phiThe operation that sums a function over a group of scalings: Φγ(ϕ)(t) = Σ ϕ(γkt).
χchiA character: a multiplicative pattern of coefficients that turns zeta into an L-function.
ψpsiChebyshev's function, ψ(x) = Σn ≤ x Λ(n). (In Lean snippets ψ is sometimes just the name of a character or function.)
