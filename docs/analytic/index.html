Analytic functions

A function is analytic if it equals its Taylor series near every point. This chapter gives examples and non-examples, shows that the decides where a Taylor series converges, and states the property that everything later depends on: an analytic function is determined by any small piece of it.

The definition

A function is analytic at a point ccc if its Taylor series about ccc converges to the function on some interval around ccc. It is analytic on a domain if it is analytic at every point of the domain.

Examples of analytic functions:

  • Polynomials, exe^{x}ex, sin⁡x\sin xsinx, cos⁡x\cos xcosx. Analytic everywhere. The Taylor series about any center converges to the function for every xxx.

  • ln⁡(1+x)\ln(1+x)ln(1+x). Analytic for x>−1x \gt -1x>−1. Its series about 0 is x−x22+x33−⋯x - \dfrac{x^{2}}{2} + \dfrac{x^{3}}{3} - \cdotsx−2x2​+3x3​−⋯, with R=1R = 1R=1: the distance to the bad point x=−1x = -1x=−1.
  • 1/(1+x2)1/(1+x^{2})1/(1+x2). Analytic at every real xxx, with radius R=1R = 1R=1 about the center 0, although nothing goes wrong on the real line at x=±1x = \pm 1x=±1. The next section explains why.
  • Combinations. Sums, products and compositions of analytic functions are analytic, and so are quotients where the denominator is not 0. So almost every formula of calculus defines an analytic function away from its bad points.

Take f(x)=11+x2f(x) = \dfrac{1}{1+x^{2}}f(x)=1+x21​. Its graph is a . The denominator is never 0 for real xxx, so the function has no bad point anywhere on the real line.

The reason appears when xxx is allowed to be complex. A power series only uses addition and multiplication, so it makes sense for a zzz in place of xxx. And for complex zzz the function does have bad points:

That distance is the radius of convergence. The rule is general:

The Taylor series of an analytic function about a center ccc converges inside the largest disc around ccc that contains no bad point, and diverges outside that disc. So the radius RRR is the distance from ccc to the nearest bad point, measured in the complex plane.

  • The natural domain of an analytic function is a region of the complex plane, and its Taylor series converge in discs.

Functions that are not analytic

Examples of functions that are not analytic:

  • ∣x∣|x|∣x∣ at x=0x = 0x=0. It has a corner there, so it has no derivative and no Taylor series.
  • The function ggg with g(x)=0g(x) = 0g(x)=0 for x≤0x \le 0x≤0 and g(x)=e−1/xg(x) = e^{-1/x}g(x)=e−1/x for x>0x \gt 0x>0. It has derivatives of every order at every point, including 0, and every derivative at 0 equals 0. Its Taylor series about 0 is therefore 0+0⋅x+0⋅x2+⋯=00 + 0\cdot x + 0\cdot x^{2} + \cdots = 00+0⋅x+0⋅x2+⋯=0. That series converges everywhere, but it equals ggg only for x≤0x \le 0x≤0. So ggg is smooth but not analytic at 0. It is the last function in Lab 4.2.

Analytic functions are rigid

For functions in general, the values on one interval say nothing about the values on another. The function ggg above agrees with the zero function on the whole left half of the line and differs from it on the right. For analytic functions this cannot happen:

If two analytic functions agree on an interval, however short, they agree everywhere that both are defined (on a connected domain). So a function given on a small region has at most one analytic extension to a larger one.

The reason: if two analytic functions agree near a point ccc, they have the same derivatives at ccc, so the same Taylor series about ccc, so they agree on the whole interval where that series converges. Move the center toward the end of that interval and repeat.

A familiar special case: a polynomial of degree 2 is determined everywhere by its values at 3 points. An analytic function behaves like a polynomial of infinite degree.

Chapter 6 uses this to extend a function beyond the region where it was first defined.

  1. The function 1/(1+x2)1/(1+x^{2})1/(1+x2) is smooth at every real xxx. Why does its Taylor series about 0 stop converging at x=±1x = \pm 1x=±1?
