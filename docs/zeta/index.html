Background · Chapter 2

The zeta function

One function packages every prime at once. Where it vanishes controls how far the prime staircase strays from its smooth guess, and the Riemann Hypothesis says exactly where those places are.

A sum that is also a product

For a number s bigger than 1, the zeta function is the sum ζ(s) = 1 + 1/2s + 1/3s + 1/4s + … Euler found that the same number is a product with one factor per prime:

ζ(s) = Πp prime 1 / (1 − p−s). Multiply the factors out and every whole number appears exactly once, because every whole number factors into primes in exactly one way.

This identity is the bridge. The left side knows only about whole numbers; the right side knows only about primes. Taking the logarithmic derivative of the product gives −ζ′/ζ(s) = Σ Λ(n) / ns, with the same weights Λ(n) as in chapter 1. So the weighted prime count is hidden in ζ′/ζ, and that quotient blows up exactly where ζ is zero.

Complex inputs and the critical strip

Riemann's step was to let s be a complex number, s = σ + it. The sum only converges for σ > 1, but the function it defines extends to the whole plane (except a pole at s = 1). Three facts organize everything that follows:

  • Right of 1 there are no zeros. The product converges there and no factor is zero.
  • A symmetry. The functional equation relates ζ(s) to ζ(1 − s), so zeros come in mirror pairs about the line σ = ½.
  • What is left. Apart from easy "trivial" zeros at −2, −4, −6…, every zero lies in the critical strip 0 < σ < 1.

The Riemann Hypothesis: every zero in the critical strip has σ = ½ exactly. Because of the mirror symmetry, it is enough to show there are none with σ > ½. Both proofs on this site aim at that one-sided statement.

Watching a zero happen

A complex function has a zero only when its real and imaginary parts vanish together. Trace the point ζ(σ + it) in the plane as t climbs: it loops around, and a zero is a loop that passes exactly through the origin.

Things to try

  • In Lab 2.1, set σ = 1.5 and raise P. Watch the product lock onto ζ: the primes rebuild the function.
  • Set σ = ½ and P = 2, then 3, then 5. A handful of primes already "know" roughly where the first zero is.
  • In Lab 2.2, set T just above 14.13, 21.02 and 25.01 and watch the path cross the origin each time. Then set σ = 0.6 and see every crossing become a near miss.

How the lab computes ζ

The defining sum does not converge in the critical strip, so the lab uses Borwein's alternating-series method with 70 terms. Checked against published values it is accurate to about six decimal places for heights up to 60, which is why the labs stop there.
