Background · Chapter 1

Counting primes

The Riemann Hypothesis is a statement about how regular the primes are. Before any zeta function, it helps to see the thing being measured: a staircase, a smooth curve that follows it, and the gap between them.

The staircase and its smooth guess

Write π(x) for the number of primes up to x. It is a staircase: flat, then up by one at each prime. Gauss noticed that near a large number x, about one number in ln x is prime. Adding up that density gives a smooth guess, the logarithmic integral li(x) = ∫2x dt / ln t. The cruder guess x / ln x has the right shape but runs low.

Weighing primes instead of counting them

Both proofs work with a weighted count that behaves better. Give every prime power pk the weight ln p, and every other number weight zero. This weight is called Λ(n), the von Mangoldt function, and its running total is Chebyshev's function ψ(x) = Σn ≤ x Λ(n).

The weights are chosen so that the smooth guess becomes as simple as possible: ψ(x) should be close to x itself. The prime number theorem says exactly that the ratio tends to 1.

The error is the whole question

How far does the staircase stray from the line? If primes were placed by fair coin flips with the right density, the error up to x would be about √x in size. The Riemann Hypothesis is equivalent to saying the primes do essentially that well:

RH holds exactly when |ψ(x) − x| ≤ C · √x · (ln x)² for some constant C and all large x. Without RH, the best proven bounds are far weaker than any power of x below 1.
