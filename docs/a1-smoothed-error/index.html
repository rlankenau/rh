The smoothed error

The Alpöge never bounds the staircase itself. It bounds a smoothed version of the error, called Gz in the source. This chapter shows what smoothing buys: the from chapter 3 disappears, and the sum over zeros becomes tame enough to add up.

Based on the definitions of Sz, Gz and ZetaLandau in the Lean source, which I read as statements. The curves are computed here from those definitions and from the first 30 zeros; the match between the two is a check I ran, not part of the formalization.

The definition

def Sz (x : ℝ) : ℝ := ∑ n ∈ Finset.Icc 1 ⌊x⌋₊, Λ n * (x / n - 1)
def Gz (x : ℝ) : ℝ := Sz x - x * Real.log x + (1 + Real.eulerMascheroniConstant) * x

In words: instead of adding the weight (n) for each n ≤ x, add Λ(n)·(x/n − 1). A contributes nothing at the moment x reaches it and then phases in gradually, so the sum has corners but no jumps. The other two terms subtract what the sum would be if primes were perfectly regular. Gz is what is left over.

What the zeros do to it

The for the smoothed sum is the one from chapter 3 with each wave divided once more by the height of its zero:

Gz(x) = 2π − ρ xρ / (ρ(ρ − 1)) − (tiny terms). If is on the line this is ln 2π + √x · Σγ > 0 2 cos(γ ln x) / (¼ + γ²).

The wave for the zero at height γ now has size about 2/γ² instead of 2/γ. Those sizes add up to a finite total, 2 + γ − ln 4π ≈ 0.0462. So on the scaled error can never leave the band ±0.0462, and a few zeros already describe it almost perfectly.

Why one side is enough

The formalization's target is a ceiling on Gz, with no floor. A makes that sufficient, and the Lean statement ZetaLandau says it for either sign: if s0·Gz(x) ≤ C·xθ for all large x, with s0 = +1 or −1, then zeta has no zeros with above θ.

The reason is the picture from Lab 3.2. A zero with real part β > θ contributes a wave of size xβ that swings both ways. A wave cannot stay under a ceiling of xθ while swinging to height xβ, and 's theorem says the other waves cannot conspire to hide it.

Things to try

  • In Lab A1.1, set K = 0 and then 1. The first zero alone carries most of the signal: its wave has height 0.0100 out of a possible 0.0462.
  • In Lab A1.2, set β = 0.55. The curve stays inside the band all the way to 20,000: a zero only slightly off the line can hide for a long time. Then try 0.7.
  • Raise γ with β fixed. Higher zeros are quieter, so they take longer to show: an off-line zero very high up would be invisible in any range a computer can reach.

Where this sits in the proof

The proof actually bounds a combined error Gm, which adds versions of Gz so that all Dirichlet are handled together, and it only needs the bound on a sparse set of scales. The map of the whole proof has the statements.
