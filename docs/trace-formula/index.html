Comparing the two

Subtract Masullo's formula from the classical one. Everything cancels except the zeros outside the strip:

∑∣Re⁡ρ−12∣≥aM(φ) ⁣(ρ−12)  =  0\sum_{\lvert\operatorname{Re}\rho-\frac12\rvert\ge a} M(\varphi)\!\left(\rho-\tfrac12\right) \;=\; 0∣Reρ−21​∣≥a∑​M(φ)(ρ−21​)=0 for every allowed φ and every a > 0.

That can hold for every test function only if there are no such zeros (chapter 16 gives the paper's argument). So Masullo's formula, for all a, is equivalent to the Riemann Hypothesis.

This comparison is mine, not the paper's. Its consequence: the lab above cannot distinguish the two formulas, because it uses is on the and so inside every strip. Whether the paper's formula is true is exactly the question of whether the hypothesis is true. The proof stands or falls on the derivation of the left side inside the completed spaces (chapters 13 and 14), which must not use the classical formula and which I have not checked.

Things to try

  • Set K = 0 and raise it slowly. The right side starts at the two pole terms and moves to the left side as zeros are added.
  • Set the width to 0.3 and compare the difference with the one at width 1. A narrow φ has a wide transform, so zeros beyond the 30th still matter.
  • Compare the prime sum with the pole terms. They are close: M(φ)(½) = ∫ φ(t)/√t dt is what the prime sum would be if every (n) were replaced by its average value 1. The zeros account for the difference.

Exercises

  1. For a zero on the critical line, ρ = ½ + iγ, and real-valued φ, write the combined term of ρ and its conjugate as a single real integral.
    Solution

    M(φ)(iγ) + M(φ)(−iγ) = 2 ∫ φ(t) cos(γ t) dt/t. This is how the lab computes the sum over zeros.

  2. Suppose there were a zero at ρ = 0.8 + 100i. For which a would it be missing from Masullo's sum?
    Solution

    Its distance from the critical line is 0.3, so it is missing whenever a ≤ 0.3. Its mirror image 0.2 + 100i is missing for the same a.

Check your understanding

  1. Why can't the lab tell the classical formula and Masullo's formula apart?

    • It uses too few primes
    • Every zero it uses is on the critical line, which lies inside every strip, so both sums are the same
    • Its numerical error is too large

    The formulas differ only in zeros at distance ≥ a from the line. No such zero is known, so no computation with known zeros can separate them.

  2. Suppose a zero existed at 0.8 + 100i. With a = 0.1, what follows?

    • Both formulas hold
    • The classical formula fails
    • The classical formula still holds and includes that zero; Masullo's omits it, so Masullo's would be false

    The classical formula is a theorem regardless. Two true identities with the same left side cannot have different right sides, so the restricted formula for all a is equivalent to the hypothesis.

  3. In the lab, the prime sum and the pole terms are close to each other. Why?

    • M(φ)(½) = ∫ φ(t)/√t dt is what the prime sum would be if Λ(n) were replaced by its average value 1
    • Coincidence
    • Because the zeros contribute nothing

    This is the prime number theorem inside the formula: the pole of ζ gives the main term, and the zeros give the fluctuation around it.
