Comparing the two

Subtract Masullo's formula from the classical one. Everything cancels except the zeros outside the strip:

∑∣Re⁡ρ−12∣≥aM(φ) ⁣(ρ−12)  =  0\sum_{\lvert\operatorname{Re}\rho-\frac12\rvert\ge a} M(\varphi)\!\left(\rho-\tfrac12\right) \;=\; 0∣Reρ−21​∣≥a∑​M(φ)(ρ−21​)=0 for every allowed φ\varphiφ and every a>0a \gt 0a>0.

That can hold for every test function only if there are no such zeros (chapter 19 gives the paper's argument). So Masullo's formula, for all aaa, is equivalent to the Riemann Hypothesis.

This comparison is mine, not the paper's. Its consequence: the lab above cannot distinguish the two formulas, because it uses is on the and so inside every strip. Whether the paper's formula is true is exactly the question of whether the hypothesis is true. The proof stands or falls on the derivation of the left side inside the completed spaces (chapters 16 and 17), which must not use the classical formula and which I have not checked.

Check your understanding

  1. Why can't the lab tell the classical formula and Masullo's formula apart?

    • It uses too few primes
    • Every zero it uses is on the critical line, which lies inside every strip, so both sums are the same
    • Its numerical error is too large

    The formulas differ only in zeros at distance ≥a\ge a≥a from the line. No such zero is known, so no computation with known zeros can separate them.

  2. Suppose a zero existed at 0.8+100i0.8 + 100i0.8+100i. With a=0.1a = 0.1a=0.1, what follows?

    • Both formulas hold
    • The classical formula fails
    • The classical formula still holds and includes that zero; Masullo's omits it, so Masullo's would be false

    The classical formula is a theorem regardless. Two true identities with the same left side cannot have different right sides, so the restricted formula for all aaa is equivalent to the hypothesis.
