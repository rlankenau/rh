Analytic continuation

The sum for ζ(s) has a value only when the real part of s is greater than 1. Analytic continuation is the fact that the function it defines there extends, in exactly one way, to the rest of the complex plane. This chapter explains what that means using a function from calculus, and then does it for ζ.

A function and a formula are different things

The geometric series 1 + x + x² + x³ + … converges for −1 < x < 1, and there its sum is 1/(1 − x). Outside that interval the series has no sum: at x = 2 its terms are 1, 2, 4, 8, …

The expression 1/(1 − x) has no such restriction. It is defined for every x except 1: at x = 2 it is −1, at x = −3 it is ¼.

So there is one function, 1/(1 − x), and the series is a way of computing it that works only on part of its domain. The series failing at x = 2 says something about the series, not about the function.

Why the extension is forced

Suppose all you knew was the series, valid on (−1, 1). Could some other function agree with it there and differ from 1/(1 − x) elsewhere? For arbitrary functions, yes: values on one interval say nothing about values on another. For the functions in this subject, no.

A function is called analytic if near every point of its domain it equals its Taylor series there. Polynomials, ex, sin x, and 1/(1 − x) away from x = 1 are analytic. Analytic functions are rigid:

If two analytic functions agree on an interval, however short, they agree everywhere that both are defined (on a connected domain). So a function given on a small region has at most one analytic extension to a larger one.

A familiar special case: a polynomial of degree 2 is determined everywhere by its values at 3 points. An analytic function behaves like a polynomial of infinite degree. All of its Taylor coefficients at one point can be read off from its values near that point, and the coefficients determine the function.

That extension, when it exists, is the analytic continuation. It is not a convention or a choice of how to assign a value to a divergent sum. It is the same function, seen on more of its domain.

Extending step by step

The Taylor series of 1/(1 − x) about another centre c is

$$\frac{1}{1-x} \;=\; \sum_{k\ge 0} \frac{(x-c)^{k}}{(1-c)^{k+1}}$$ This is valid when |x − c| < |1 − c|.

The series converges out to the distance from the centre to the bad point x = 1, and no further. Starting from the original series (centre 0, valid on (−1, 1)), compute the function and its derivatives at c = −0.9. The series about that centre is valid on (−2.8, 1), which reaches points the original did not. Repeating this extends the function as far to the left as desired.

On the real line this process cannot get past x = 1. In the complex plane it can: a chain of overlapping discs can go around the bad point, and the function on the far side is still determined.

Continuing zeta

The same thing happens for ζ. Chapter @@ch:zeta@@ estimated what is left after N terms of the sum: about N1 − s/(s − 1). Turn that around. Take the first N terms and add the estimate of the rest:

$$\zeta(s) \;=\; \lim_{N\to\infty}\left[\;1+\frac{1}{2^{s}}+\dots+\frac{1}{N^{s}} \;-\; \frac{N^{1-s}}{1-s}\;\right]$$

For σ > 1 the extra term tends to 0 and this is the original sum. But the limit exists for every s with σ > 0 except s = 1, and it is analytic there. By the rigidity above it is the continuation of ζ to the half-plane σ > 0.

In the picture of chapter @@ch:complex-zeta@@: for 0 < σ < 1 the chain of arrows does not settle. It circles in an ever wider spiral, and the term N1 − s/(1 − s) is exactly the arrow from the centre of that spiral to the chain's current end. Subtracting it leaves the centre, and the centre is ζ(s).

The whole plane

Riemann gave two further formulas that extend ζ to every complex number except s = 1. At s = 1 the function has a pole: it behaves like 1/(s − 1), as in Lab @@ch:zeta@@.2. From here on, ζ(s) means this extended function.

The extended function takes the values ζ(0) = −½ and ζ(−1) = −1/12. The original sum at s = −1 would be 1 + 2 + 3 + 4 + …, which has no sum. The statement "1 + 2 + 3 + … = −1/12" is shorthand for ζ(−1) = −1/12, in the same way that "1 + 2 + 4 + 8 + … = −1" is shorthand for the value of 1/(1 − x) at x = 2.

Exercises

  1. Derive the Taylor series of 1/(1 − x) about the centre c.
    Solution

    Write 1 − x = (1 − c) − (x − c) = (1 − c)(1 − u) with \(u = \dfrac{x-c}{1-c}\). Then $$\frac{1}{1-x} \;=\; \frac{1}{1-c}\left(1+u+u^{2}+\cdots\right)$$ valid for |u| < 1, that is, |x − c| < |1 − c|.

  2. Use the formula for ζ with N = 1, and half of the last term removed, to estimate ζ(½).
    Solution

    1 − ½ − 1½/(1 − ½) = 1 − ½ − 2 = −1.5. The true value is −1.4604. With N = 10 the same recipe gives −1.4617.

  3. The function |x| agrees with the function x on the interval (0, 1) but not at x = −1. Why does this not contradict the rigidity of analytic functions?
    Solution

    |x| is not analytic at x = 0: it has a corner there and no Taylor series. Rigidity is a property of analytic functions only. On any domain where |x| is analytic, such as x > 0, it does equal x.

Check your understanding

  1. The geometric series diverges at x = 2, and 1/(1 − x) equals −1 there. Which statement is right?

    • The series secretly adds up to −1
    • The function has the value −1; the series is a way of computing the function that works only for |x| < 1
    • The function is undefined at 2

    The sum 1 + 2 + 4 + … has no value. The function it came from does, and analytic continuation is about the function.

  2. Why is there only one analytic continuation?

    • Two analytic functions that agree on any interval agree wherever both are defined
    • Mathematicians agreed on a convention
    • Because the series converges everywhere

    Rigidity: the values near one point fix every Taylor coefficient, and so the whole function. This is what makes it legitimate to speak of ζ(s) where the sum diverges.

  3. In Lab @@n@@.3 with σ = 0.5 the chain of arrows never settles. What is ζ(s) in that picture?

    • The point where the chain ends
    • It does not exist
    • The centre that the chain spirals around

    The chain's end is the centre plus the arrow N1 − s/(1 − s), whose length grows like N1 − σ. Removing that arrow leaves the centre, which is the continued function.
