Counting primes

The Riemann Hypothesis is equivalent to a bound on the error in the standard estimate for the number of primes up to x. This chapter defines the count, the estimate, and the error.

The staircase and its smooth guess

Write π(x) for the number of primes up to x. It is a staircase: flat, then up by one at each prime. Primes thin out as numbers get bigger, and Gauss noticed the rule: near a large number x, about one number in every ln x is prime. Around a thousand that is one in 7; around a million, one in 14.

If the chance of being prime near t is 1 / ln t, then adding up those chances for every t from 2 to x should estimate how many primes there are up to x. That running total is called the logarithmic integral, written li(x) = ∫2x dt / ln t. A cruder estimate, x / ln x, has the right shape but runs low.

Weighing primes instead of counting them

Counting each prime as 1 turns out to give awkward formulas. Number theorists get cleaner ones from a weighted count. Give every prime power pk the weight ln p, and every other number weight zero. This weight is called Λ(n), the von Mangoldt function, and its running total is Chebyshev's function, written ψ(x) = Σn ≤ x Λ(n): add up the weights of all whole numbers up to x.

The weights exactly cancel the thinning-out. Primes near x are rarer by a factor of ln x, but each one counts for ln x, so the weighted total should grow like x itself. The prime number theorem says that it does: ψ(x) divided by x gets closer and closer to 1.

The error is the whole question

How far does the staircase stray from the line? If primes were placed by fair coin flips with the right density, the error up to x would be about √x in size. The Riemann Hypothesis is equivalent to saying the primes do essentially that well:

The Riemann Hypothesis is true exactly when the gap between ψ(x) and x is never more than about √x. Precisely: the gap is at most C · √x · (ln x)² for some fixed number C. What has actually been proved so far is much weaker: the gap is known to be smaller than x, but not smaller than any fixed root of x.

Exercises

  1. Compute ψ(10) by hand.
    Solution

    The prime powers up to 10 are 2, 3, 4, 5, 7, 8, 9. The weights are ln 2 three times (for 2, 4, 8), ln 3 twice (for 3, 9), ln 5 and ln 7. The total is ln(2³ · 3² · 5 · 7) = ln 2520 ≈ 7.83.

  2. Show that ψ(x) is the logarithm of the least common multiple of 1, 2, …, ⌊x⌋.
    Solution

    The least common multiple contains each prime p to the highest power pk ≤ x. Its logarithm is therefore k · ln p summed over primes, and ψ adds ln p once for each of p, p², …, pk, which is the same total. Exercise 1 is the case lcm(1, …, 10) = 2520.

  3. Use Gauss's density 1 / ln x to estimate how many primes lie between 1,000,000 and 1,001,000.
    Solution

    ln 1,000,000 ≈ 13.8, so about one number in 13.8 is prime there: roughly 1000 / 13.8 ≈ 72 primes.

Check your understanding

  1. Why does ψ give a prime p the weight ln p instead of counting it as 1?

    • So that the sum is always a whole number
    • Near x about one number in ln x is prime, so weights of ln p make the total grow like x itself
    • Because large primes matter less than small ones
    • So that the sum converges

    The weight cancels the thinning-out of the primes. The comparison function for ψ is then simply x, where for π it is the integral li(x). Note the weight makes large primes count more.

  2. The prime number theorem says ψ(x) is "close to" x. Which reading is correct?

    • ψ(x) − x stays below some fixed number
    • ψ(x) − x eventually becomes 0
    • The ratio ψ(x)/x tends to 1, while the difference can still grow

    The theorem controls the error only relative to x. The difference ψ(x) − x is unbounded; how fast it can grow is exactly what the Riemann Hypothesis is about.

  3. There are 78,498 primes below one million. Without computing, how many would you expect between one million and two million?

    • Somewhat fewer, because the density 1/ln x keeps falling slowly
    • The same number, because the stretch has the same length
    • About half as many
    • More, because the numbers are larger

    The density falls from about 1/13.8 at one million to 1/14.5 at two million. The true count is 70,435, about 10% fewer.
